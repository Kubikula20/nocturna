PROJEKT – RESTAURACE NOCTURNA
Popis projektu: Webová stránka fiktivní restaurace Nocturna, která se zaměřuje na moderní evropskou kuchyni a nabídku vín.
Využití AI: AI jsem využil při tvorbě textů na jednotlivé stránky webu a jako pomocníka při výběru barev a celkového vzhledu restaurace. HTML a CSS kód jsem vytvářel samostatně.
Použité technologie: HTML, CSS
